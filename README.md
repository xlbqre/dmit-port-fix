## 先搞清楚：你遇到的是哪种情况？

**DMIT 端口被封**是一个笼统的说法，实际上可能对应三种完全不同的故障：

**定义块：** DMIT VPS 的连接失联，通常分三类——IP 被 GFW 封锁（国内无法访问，国外正常）、单个端口被封（IP 可 ping 通但 SSH 连不上）、本地防火墙配置问题（自己改设置时把自己锁在外面了）。三种情况的解决方式完全不同，必须先判断再处理。

### 怎么判断是哪种情况？

打开 [ping.chinaz.com](http://ping.chinaz.com)，输入你的 VPS IP 地址，跑一次多地 ping 测试。

看结果：

- **国内全红、国外全绿** → IP 被 GFW 封锁，端口问题是次要的
- **国内国外都红** → VPS 可能没开机，或者宕机了
- **能 ping 通，但 SSH 连不上** → 你的 IP 没问题，22 端口被封了
- **SSH 能连，某个特定端口打不开** → 该端口被封，或者防火墙没放行

再用端口检测工具（比如 tcp.ping.pe）专门检测 22 端口。能 ping 通 IP 但端口超时，基本就是 **DMIT 端口被封**这个情况了。

## 端口被封的三种处理路径

### 路径一：修改 SSH 默认端口（最常见）

22 端口是全球扫描爆破的重灾区，也是 GFW 最喜欢封的端口之一。解决方法很直接——换个端口。

**操作步骤如下：**

1. 通过 DMIT 后台控制台的 VNC 功能登录服务器（不依赖 SSH，专门为这种情况设计的）
2. 编辑 SSH 配置文件：`vi /etc/ssh/sshd_config`
3. 找到 `#Port 22` 这一行，去掉 `#`，在下面新增一行 `Port 你的新端口号`（建议选 49152-65535 范围内的端口）
4. **先不删掉 22**，两个端口并存，先测试新端口能连上再说
5. 防火墙放行新端口：`firewall-cmd --zone=public --add-port=新端口/tcp --permanent && firewall-cmd --reload`
6. 重启 SSH 服务：`systemctl restart sshd`
7. 新开一个终端窗口，用新端口测试连接：`ssh -p 新端口 -i 密钥文件 root@你的IP`
8. 确认新端口能用之后，再回去把 22 端口从配置文件里删掉

中间有个坑要特别注意：如果你用的是 CentOS，还需要让 SELinux 放行新端口，否则改了也没用。命令是 `semanage port -a -t ssh_port_t -p tcp 新端口`。

### 路径二：特定业务端口被封（443、80、代理端口等）

不只是 SSH，其他端口也可能被封。比如你在 DMIT 上搭了某个服务，用了一个特定端口，结果从国内访问不了。

判断方法：用端口检测工具检测那个端口。能通就是服务没跑起来，不能通才是端口问题。

处理思路：换端口。把服务配置里的监听端口改掉，同时确保防火墙放行了新端口。

443 和 80 这两个端口在某些情况下也会被封，换成其他端口有时候能绕开，但不是百分之百有效——GFW 的封锁逻辑比端口更复杂。

### 路径三：ICMP 和所有 TCP 端口全封——IP 被彻底封了

这种情况下换端口没用。IP 直接挂了。

## FAQ：关于 DMIT 端口被封的常见问题

**Q：DMIT VPS 的端口被封了，用 VNC 还能登录吗？**

A：可以。DMIT 后台提供 VNC 控制台，这是独立于 SSH 的登录方式，不走 22 端口，端口被封不影响 VNC 登录。这也是修改 SSH 端口、排查问题的主要入口。

**Q：DMIT 端口被封和 IP 被墙有什么区别？**

A：端口被封是 GFW 屏蔽了特定端口（比如 22），但 IP 本身还是通的——国外 ping 和国内 ping 都有响应，只是那个端口连不上。IP 被墙是整个 IP 在国内不可达，国外正常、国内全超时。判断方法：先 ping IP，再用工具单独检测端口。

**Q：DMIT 能免费换 IP 的条件是什么？**

A：洛杉矶 Pro 和 EB 系列（不含 sPro），需满足：实例购买超过 7 天、距上次换 IP 超过 15 天、且 ICMP 和所有 TCP 端口均被封禁。只有单个端口被封不够格免费换，要全封才行。其他套餐换 IP 收费 $5/次。

**Q：DMIT 端口被封，能用优惠码吗？**

A：优惠码和端口封禁是两件事。目前有效优惠码包括：洛杉矶 EB 系列 `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF`（季付及以上 8 折循环）；香港和东京 T1 系列 `202510_HKG_TYO_T1_30OFF_RECURRING`（季付及以上 7 折）；东京 T1 系列 `2025-TYO-T1-HI-GSL-NON-MONTHLY-30OFF`（季付及以上 7 折）。使用前确认适用套餐和计费周期。

**Q：DMIT 的 Pro 系列比 Eyeball 系列更不容易被封端口吗？**

A：从线路稳定性来说，Pro 系列确实更稳——它保证不切换路由，且 IP 质量通常更好。但被封端口本质上是 GFW 的行为，和你跑什么服务、流量特征有更直接的关系，和线路档次关系不是绝对的。Pro 系列的优势是被封 IP 后换 IP 更方便，因为符合免费换 IP 条件的概率更高。
